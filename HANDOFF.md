# Handoff — portfolio overhaul (2026-09-24)

State of the repo at the end of the session that audited the whole site and
worked through a four-phase improvement plan. Branch:
`portfolio-overhaul` (not yet merged to `main`).

## What was done

**Phase 0 — ship-blockers**
- Replaced the template author's identity: "JM" monogram, favicon, PWA icons
  and the default social card (it read "HAMISH WILLIAMS"), all generated by
  `scripts/brand-assets.cjs`. Storybook metadata rebranded.
- Mera Monitor case study rewritten around the owner's own contribution;
  removed stock photos, real faces, a 1.2 MB empty hero, a screenshot with the
  owner's Windows taskbar, and the line criticising the employer's auth. One
  real-looking name blurred in `mm-time-claim.webp`.
- Experience section (`app/routes/_index/experience.tsx`) rendered from
  `timeline` in `experience.ts`; visible email; résumé button that appears when
  `config.resume` is set.
- Finished the in-progress `ProjectReveal` (was failing lint and could hide
  content permanently).
- Security: removed the `@remix-run/router` override that pinned a vulnerable
  version; nodemailer 6 → 10; `/api/set-theme` allowlists light/dark and checks
  origin; root loader no longer sets a cookie on every response; missing
  `SESSION_SECRET` warns instead of taking every route down; stricter email
  validation; non-form bodies get 400.

**Phase 1 — new work from GitHub**
- New case studies: `personal-vault` (flagship) and `analytics-mcp-server`
  (anonymised). CareerPilot and Kundli updated to match their current repos
  (Kundli's "no AI required" and CareerPilot's "never submits" were false).
- Skills lists rebuilt from real project stacks; `/uses` rewritten.
- "Latest commits" strip from `app/data/github-activity.json`, refreshed by
  `scripts/github-activity.cjs` and a weekly workflow.

**Phase 2 — performance & reliability**
- `DecorativeBoundary` around every WebGL scene: no GPU no longer means an
  error page (verified in headless Chromium, which has none). Device cards
  fall back to the poster.
- WebGL context released on unmount (`forceContextLoss`); sphere moved out of
  the theme-keyed transition; low-power sphere tier; time-based rotation.
- `Image` `priority` prop (SSR src, eager, fetchpriority=high). Animated Screen
  Coach image 1.2 MB → 390 KB. Profile srcset candidates now share one crop.
- Model loader: parallel fetch, cancel on unmount, failures reach the boundary.
- A11y: touch-visible video pause, persistent live region + focus on contact
  success, 24px+ mobile nav targets, `100svh`, reduced-motion delays, error page
  heading, marquee duplicate hidden. Theme follows the OS via the
  `Sec-CH-Prefers-Color-Scheme` client hint when no choice is saved.

**Phase 3 — SEO & content**
- Titles "X case study | Jatin Mangla"; one canonical URL form
  (`app/utils/url.ts`); `/home` duplicate removed (home is now
  `routes/_index/`, plus a `vercel.json` redirect); generated `robots.txt`;
  sitemap `lastmod`; Person + per-case-study CreativeWork JSON-LD.
- Deleted dead code (post layout, code/list components, unused utils, hooks,
  assets) and the unused MDX pipeline (~120 packages).

**Phase 4 — tests, CI, hardening**
- Tests: 100 unit (image dimensions, routes, CSP, boundary, API routes…), 48
  e2e (axe on every page in light, dark and mobile; contact flow; sitemap;
  `/home` 404). E2E route list derives from `projects.ts`.
- CI: read-only permissions; production `npm audit` gate at `critical`;
  e2e + Lighthouse against the real deployment via `deployment_status`
  (`BASE_URL`); Dependabot ignores React majors and three minors.
- Nonce-based CSP sent as **Report-Only** from `entry.server.tsx`.
- `@types/three` aligned to three 0.161; `@vercel/remix` moved to dependencies.

Verified at handoff: typecheck, lint, 100/100 unit, build, 48/48 e2e.
`npm audit --omit=dev`: 9 left (5 moderate, 4 high, 0 critical) — all on the
Remix 2 / React Router 6 line or `@vercel/remix`.
